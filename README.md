# 刹车模拟器｜BRAKE LAB

一款原创、荒诞、抽象的 3D 网页小游戏，主题是“没有刹车，只有下山”。它不是汽车安全性能测评，也不代表任何真实品牌或事件。

## 环境要求

- Node.js 20.19+ 或 22.12+（当前开发环境使用 Node.js 24）
- 支持 WebGL 2 的常见 PC 浏览器

## 安装与启动

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建：

```bash
npm run test
npm run build
npm run preview
```

## 操作

- 主菜单点击“开始下山测试”，在 DIY 页选择材质、粗细和加固。
- 在同一 DIY 页用鼠标绘制标志，选择颜色和笔刷粗细，然后点击“注入玄学能量”。空白画板会使用 BRAKE LAB 默认制动踏板图形。
- 同一幅车标只能附魔一次；修改或清空画板后才可重新抽取。
- 汽车自动沿固定盘山公路行驶和转向。
- 长按 `Space`：逐渐加深刹车。
- 松开 `Space`：刹车快速回弹。
- 到达弯道检查点时，车速严格大于提示的安全速度会立即飞出悬崖。
- 踏板耐久是隐藏数值；持续重踩可能使踏板突然断裂。
- 驾驶过程中可点击左上角“退出本局”返回主菜单。
- 主菜单可静音并调节整体音量；首次点击页面后会按浏览器规则解锁音频。

### P1.5 视觉优化

- 路面改为深灰色低多边形柏油材质，新增黄色中心虚线、白色边线、路肩和金属护栏。所有道路可视几何仍直接由自动驾驶的同一条 `CatmullRomCurve3` 生成。
- 山路两侧新增跟随路线的地形带、悬崖岩块、密集低多边形树林、多层远山和渐变天空。
- 驾驶界面改为“大视野、小驾驶舱”：紧凑方向盘、仪表台、中控、风挡立柱和车头占据底部约 25% 空间。
- HUD 调整为顶部紧凑路线进度、左下仪表速度与制动深度、右上小型急弯警告，右下仅预留 P2 踏板特写窗口。
- 宽屏、窄屏与低高度窗口均有独立的响应式 HUD 收缩规则。
- P1.5 不包含踏板 DIY、耐久或断裂系统；自动下山、空格刹车、弯道判定和胜负规则未修改。

### P2 踏板 DIY 与断裂系统

- 下山前新增 DIY 页：七种材质（钢铁、铝合金、塑料、钛合金、木头、豆腐、饼干）、0–100 粗细滑块、三级加固。不包含预算和零件拼装。
- `PedalBuilder` 集中生成踏板面板、可变粗细踏板臂、固定基座和加强件；DIY 预览与游戏内特写使用同一模型逻辑。
- 右下角 PEDAL CAM 已替换为独立 Three.js 实时特写，包含当前 DIY 踏板和简化鞋子；踩下深度与 P1 空格蓄力状态使用同一数值。
- 材质、粗细和加固共同决定隐藏最大耐久和每秒损耗；损耗公式无随机数，相同配置和输入可复现。
- 耐久耗尽后只触发一次断裂，锁定刹车输入，踏板组件立即分离并弹飞，播放程序生成的基础“咔嚃”音效，然后进入断裂失败结算。
- 结算页显示材质、粗细和加固；“再来一把”保留配置并重置耐久，“重新设计踏板”返回 DIY 并保留上次选项。
- P2 阶段只包含基础断裂音效、分离弹飞和失败转场；完整慢动作、鬼畜字幕及车机播报现已在下方 P4 中完成。

### P3 车标绘制与半随机附魔

- DIY 页面现拆分为“踏板 DIY”和“车标附魔”两个选项卡，继续保持左侧预览、右侧操作；切换时不会销毁踏板配置、绘图笔画或附魔结果。
- 车标页使用 384×384 Canvas 2D 画板，提供六种颜色、笔刷粗细、撤销和清空功能；鼠标或指针可直接绘制。1920×1080 与 1366×768 桌面窗口下主要操作无需整页纵向滚动。
- 本地统计绘画点数、轨迹长度、覆盖网格、覆盖率与密度，不使用图像识别模型。密集线条提高耐久类附魔权重，稀疏线条提高低损耗类权重，大面积覆盖提高高制动力类权重。
- 附魔池集中配置为钢铁意志、轻盈制动、重踩艺术家、实验室祝福、天命已尽、精神制动、喇叭开光和中控嘴硬；特征只改变抽取权重，不保证固定结果。
- 同一画作只允许抽取一次；系统按实际笔画生成稳定指纹并记录结果。继续绘制或清空后可为新画作抽取，但撤销回旧画作时会恢复旧附魔并保持锁定，不能靠撤销重复刷取。空白画板使用 BRAKE LAB 默认图形标志并按普通权重抽取。
- 数值附魔已实际接入 P2：最大耐久、单位时间损耗和 P1 制动力分别使用附魔倍率；纯整活附魔保持数值不变。
- 车标显示在 DIY 附魔结果、方向盘中央和结算页；方向盘中心徽标已放大，结算页同时展示附魔名称。
- “再来一把”保留车标与附魔并重置驾驶/耐久状态；“重新设计踏板”返回 DIY 后保留当前结果，修改画作后才能重新附魔。
- 绘图特征、加权抽取、画作指纹/撤销锁定、一次性规则、三种数值倍率和重试不叠加均有 Node 内置逻辑测试，随机函数可注入以便复现。

### P4 鬼畜断裂演出与最终完善

- 失败流程使用集中状态机：`DRIVING → BRAKE_BREAK_CINEMATIC → CRASH_CINEMATIC → RESULT`；弯道超速直接进入 `CRASH_CINEMATIC`，不会误播踏板断裂镜头。
- 踏板断裂触发后锁定输入并冻结驾驶数据。右下角实时踏板窗口约 0.3 秒放大到屏幕中央，复用 P2 参数化踏板播放脚猛踩、踏板分离旋转飞出、脚踩空、镜头轻震以及“断！/咔嚓！”大字。
- 演出使用独立时间进度，不修改驾驶模拟时间。断裂演出结束后自动切换到第三人称低多边形汽车飞车镜头。
- 第三人称汽车在失败位置生成，根据道路前后切线判断弯道外侧，保留向前惯性并沿夸张抛物线越过路沿、旋转下坠；断裂和超速失败共用该模型与轨迹。
- 新增车机字幕播报：踏板断裂“检测到刹车系统主动离职。”、超速“检测到车辆正在申请起飞。”、成功“恭喜，您和踏板都活着到了山脚。”。
- 结算完整展示下山距离、存活时间、最高车速、踩踏次数、踏板三项配置、标志、附魔、失败原因/通关状态和称号。称号包含重踩艺术家、踏板终结者、豆腐渣工程、刹车研究员、下山成功、就差亿点点。
- “再来一把”会清理演出与音效、重置路线、驾驶统计和踏板耐久，同时保留 DIY、车标及附魔且不会重复叠加；“重新设计”返回双选项卡 DIY。
- 使用 Web Audio 程序生成踩踏、断裂、飞车、成功和失败提示音，不依赖联网资源；支持静音、音量调节和浏览器自动播放限制降级，字幕始终可用。
- 飞车模型、踏板模型和音频管理器均在初始化时创建并跨局复用；事件监听只绑定一次。连续十局状态循环有自动测试覆盖。
- 当前自动测试集共 31 项，覆盖 P0～P4.7 关键逻辑。

### P4.5 视觉与演出优化

- 驾驶舱挡风玻璃由单独 A 柱补全为上横梁、双 A 柱、内侧饰条和下沿过渡，透明开口仍保留约 75% 的道路视野，方向盘和 HUD 不遮挡道路中心。
- 新增统一的 `TerrainHeightSampler`。路侧地形生成、树木、岩石、护栏和实体路牌共享同一高度数据；岩石按几何包围盒底面贴地，树干按模型局部底面贴地，护栏立柱从采样地面起算。
- 树木的距离、尺寸和朝向改为固定种子的可复现变化；章节提示牌由始终朝向镜头的大型 Sprite 改为更小的路侧实体牌，减少遮挡和悬浮感。
- PEDAL CAM 进一步放大到桌面宽度 300～440px、视口高度约 33%（最高 340px），窄屏为 230～330px；黄色粗描边和危险状态光晕强化其核心窗口感。
- 特写相机从 48° 收至 41°，机位向前并把观察中心下移到踏板与鞋之间；踏板模型放大 20%，鞋放大约 14%～22%，优先突出脚、鞋面、踏板面和踏板杆。
- 制动条显示“未踩 / 轻踩 / 中踩 / 深踩 / 踩到底”力度层次，并用黄橙红渐变、增粗进度条与满刹脉冲表达踩踏强度；接近极限时特写窗发出红色警示并轻微震动。制动力、耐久公式和断裂阈值不变。
- P4.7.1 当时采用脚跟固定、脚踝旋转的踩踏姿态；这一早期方案已被文末的“整脚向前踩”版本取代。
- P4.7.2 降低断裂演出的眩晕感：移除整屏无限抖动，并避免满刹 PEDAL CAM 脉冲动画覆盖断裂特写的居中变换；只保留断裂初段一次短促、低幅冲击。飞车时车辆在第三人称拉镜期间即开始运动，驾驶舱在转场约 0.8 秒时淡出并隐藏，随后明确锁定跟拍视角。
- 断裂特写加重脚踩空的下冲与抬转动作，踏板断件更快向外旋飞；最后一脚、咔嚓字效和独立慢动作流程保持现有状态机，不引入新的损坏阶段。
- Web Audio 增加随实际车速变化的低频引擎声和风噪循环，进入菜单、断裂、飞车或结算时会平滑静音；仍遵守浏览器首次交互解锁、静音和总音量设置。
- 未修改自动下山、空格蓄力、超速检查点、踏板耐久、附魔倍率、失败状态机和结算规则。
- 浏览器实际检查覆盖 1280×720 宽屏与 480×563 窄屏，确认主道路、前方弯道和 HUD 无互相遮挡。修改前后截图位于 `artifacts/p45-before-driving.jpg`、`artifacts/p45-after-driving.jpg` 和 `artifacts/p45-after-wide.jpg`。

### P4.6 地形与场景接地修复

- `TerrainHeightSampler` 现在同时服务于地形网格和静态物体，并支持路线进度提示，避免发卡弯附近把相邻但不同高度的路段误当成同一地面。查询超出实际地形覆盖范围时会明确返回无效结果。
- 道路新增低多边形实体路基；道路两侧采用路肩、缓坡、岩壁和谷底五层连续横断面，最外层与谷底平面连接，补齐第三人称视角下原先暴露的道路底部空洞。
- 岩石限制在实际坡面范围内并缩小极端尺寸，使用中心与四个足迹点共同采样坡面高度，再按坡度差适度嵌入地面；树木同样只在有效坡面内生成。
- 护栏改为按路线采样的连续实例化网格，立柱从道路边缘地面起算，横梁同时跟随道路切线与坡度，减少断开和悬空，并降低大量独立 Mesh 的绘制开销。
- 飞车镜头保留原有离心方向和前向惯性，仅增加车辆与相机的地形高度下限，避免演出过程中穿入山体。
- 新增 3 项地形回归测试：横断面/高度查询一致性、发卡弯路线提示与有效范围、多点岩石接地。生产构建通过，浏览器控制台无错误。
- 修复后截图位于 `artifacts/p46-first-person.jpg` 与 `artifacts/p46-third-person.jpg`。

### P4.7 场景修复、踩踏反馈与断裂演出优化

- 护栏立柱沿道路外侧边线采样地形高度，底部贴地；横梁由相邻采样点之间的实际三维距离和方向生成，跟随弯道及坡度连续连接，反光片仍按间距复用实例网格。
- 踏板相对 `brakeDepth` 的转动、下压和前后位移加大；PEDAL CAM 使用同一踏板模型并放大取景，补齐低多边形鞋头、鞋面、鞋底、后跟、踝部和裤管。排查发现鞋体几何虽已创建，但之前未挂入鞋组，因此实际只看得到裤管和踝部；现已修正层级并调整侧向取景。脚踝旋转属于此阶段的旧方案。
- 断裂失败采用独立演出进度：约 1 秒放大踏板窗口、猛踩并断开，随后脚踩空、部件旋转飞出；字幕与“咔嚓”保留，演出后段逐步回到驾驶舱视角并向前失控冲出，再平滑过渡至第三人称飞车和结算。
- 踏板断裂从触发到飞车结束约 7.6 秒；超速失败仍跳过踏板特写，采用约 3.45 秒的较短飞车演出。驾驶规则、弯道判定、踏板损耗和结算条件均未改变。
- 场景地形的平滑起伏使用连续确定性函数，避免相邻采样段出现随机高度跳变；静态道路物件仍在生成时对齐，不新增每帧地形射线检测。
- 增加对演出时间轴、回舱前冲、阶段转换及约 6–8 秒总时长的回归断言。自动测试 31/31 通过，生产构建通过；浏览器检查驾驶视野、护栏连续性、退出按钮和踏板特写，无控制台错误。

## 已知限制

## 最新 PEDAL CAM 踩踏表现

- 根据最新反馈移除右侧侧向推杆、套筒和连杆。当前踏板仅保留宽矩形防滑面、前方固定支架与转轴、绕轴下压的活动臂；DIY 预览与驾驶特写仍复用同一个参数化 `PedalModel`。
- `brakeDepth` 同步驱动踏板转角和整只脚的前移、轻微下移；脚与小腿保持固定姿态，鞋跟不再钉在原地，松开后整脚退回。PEDAL CAM 的 `BRAKE FORCE` 只显示已有踩踏深度，不显示隐藏耐久。
- 针对「像脚尖推刹车」的反馈，将鞋相对地面的固定倾角从约 24° 提高到约 47°，并同步下调脚部与地板的基准高度。未踩、中踩、满踩仍保持同一脚型和整脚前推进程；对比截图见 `artifacts/pedal-angle-idle.jpg`、`artifacts/pedal-angle-medium.jpg`、`artifacts/pedal-angle-full.jpg`。
- 断裂特写沿用原状态机：最后一脚继续向前压，踏板飞离后脚继续向前、向下踩空，再进入既有飞车和结算流程。制动力、耐久、DIY、附魔与关卡规则未改。
- 浏览器检查未踩、中踩、满踩的脚部前移与踏板下压，并用低耐久踏板验证断裂后继续前冲踩空、正常进入失败结算；控制台无错误。新截图见 `artifacts/pedal-forward-idle.jpg`、`artifacts/pedal-forward-medium.jpg`、`artifacts/pedal-forward-full.jpg`、`artifacts/pedal-forward-break.jpg`、`artifacts/pedal-forward-miss.jpg`；旧版横向推杆截图保留在 `artifacts/pedal-travel-*.jpg` 仅供对比，不代表当前效果。
- 本次 32 项逻辑测试全部通过，Vite 生产构建通过；构建仍有单包超过 500 kB 的提示，不影响游戏运行。
