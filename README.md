# 刹车模拟器｜BRAKE LAB

一款使用 Three.js 制作的第一人称、低多边形 3D 下坡生存游戏。车辆自动前进，玩家控制方向与刹车，挑战在踏板断裂或冲出悬崖前行驶得更远。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run test
npm run build
npm run preview
```

## Windows 免安装包

在开发电脑上运行 `powershell -ExecutionPolicy Bypass -File .\scripts\package-windows.ps1`。脚本会先运行测试和生产构建，再生成 `release` 目录下的 ZIP 包。目标电脑解压后双击 `start-game.bat` 即可运行；不需要安装 Node.js 或联网，但需要 Windows 10/11 自带的 PowerShell 和现代浏览器。

发布构建不包含调试 source map，并将 Three.js 与游戏入口分块。运行时会依据设备内存和处理器核心数自动选择较轻的渲染档位；游戏规则不受影响。

## 操作

- 汽车自动沿无限生成的山路下坡，无油门。
- `A` / `D` 或 `←` / `→` 控制车辆在道路上的左右位置；方向盘会随输入转动并回正。
- 长按 `Space` 踩刹车，松开后踏板回弹。
- 驾驶中可使用左上角按钮退出本局。
- 驾驶中可点击左上角“暂停”或按 `P` 暂停／继续；暂停会冻结驾驶和计时，并释放已按住的控制键。
- 右上角按钮可切换全屏模式，按 `Esc` 退出全屏；全屏下也可再次点击按钮退出。
- 开始前可配置踏板并绘制车标；踏板材质、粗细、加固和车标附魔会影响本局属性。
- 高速过弯会产生向弯道外侧的横向趋势，冲出路沿或踏板耐久耗尽会导致失败；没有固定终点。结算后可以重试或重新设计。

## 功能概览

- 五类按距离逐步解锁的道路模块：普通直坡、普通弯道、急弯、陡坡、连续弯。前方动态生成，后方旧路段释放；路线种子固定，便于测试和复现。
- 第一人称驾驶舱、实时转向、转弯时轻微车身侧倾与回正、弯道预警、踏板状态百分比及第三人称飞车演出。
- 首页直接使用提供的 BrakeBreaker 插画作为封面；道路场景加入紫红夕阳、太阳、蓝紫色远山、黄色弯道指示牌和真正分隔的黄色虚线。方向盘有两只低多边形手，会跟随转向。
- 踏板 DIY、实时 3D 踏板特写、耐久断裂演出和游戏结算。
- 踩踏越深磨损越快，高速深踩还有额外磨损；原有材质、粗细、加固、附魔倍率和断裂阈值继续生效。
- Canvas 车标绘制与一次性半随机附魔，结果会保留到重试。
- 响应式 HUD、车机字幕、程序生成音效及静音和音量调节。

## 当前限制

- 车辆、山体、树木和路牌使用代码生成的低多边形模型。
- 音效由 Web Audio 程序生成；车机播报以字幕为主。
- 自动化逻辑测试使用 Node.js 内置测试运行器。
- 无限路线采用轻量几何和简化横向动力学，不是完整汽车物理模拟。暂不包含其他车辆、天气或障碍物。
- `src/config/route.js` 等旧版五段固定路线模块仍保留供历史测试参照，但 2.0 实际游玩使用 `EndlessRoute`。

## 2.0 验证

- 踏板强度已重新平衡：全部七种材质及粗细、加固、附魔组合在约 126 km/h 持续踩到底时，约 2～55 秒内会断裂；轻踩较慢，不踩不损耗。材质和改装差异、附魔倍率仍然有效。
- 路段入口采用约 40 米的坡度渐变，下坡加速跟随实际路面坡度变化，不再在陡坡边界突然切换。
- `npm test`：42 项通过，包含转弯侧倾与回正、全组合断裂时间、坡度/加速连续性、路线连续性、难度分层、前后路段生成/回收、地形接地、转向外甩、高速刹车磨损与重试重置。
- `npm run build`：生产构建通过。
- 浏览器试玩：已检查 1366×768 桌面画面、DIY/附魔进入流程、起步道路、弯道、超出路沿后的飞车结算、豆腐踏板断裂特写及重试。画面保持第一人称驾驶、右下踏板特写及完整结算。
- 新封面与场景在桌面及窄窗口实际检查过；窄屏封面使用完整图片适配，避免标题被左右裁掉。
