# 刹车模拟器｜BRAKE LAB

一款使用 Three.js 制作的低多边形 3D 网页小游戏：汽车自动下山，玩家通过踩刹车挑战山路和踏板耐久。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run test
npm run build
npm run preview
```

## 操作

- 汽车自动沿固定山路行驶。
- 长按 `Space` 踩刹车，松开后踏板回弹。
- 驾驶中可使用左上角按钮退出本局。
- 开始前可配置踏板并绘制车标；踏板材质、粗细、加固和车标附魔会影响本局属性。
- 超速过弯或踏板耐久耗尽会导致失败；完成路线可通关。结算后可以重试或重新设计。

## 功能概览

- 五段固定 3D 盘山路线、第一人称驾驶舱、弯道预警和第三人称飞车演出。
- 踏板 DIY、实时 3D 踏板特写、耐久断裂演出和游戏结算。
- Canvas 车标绘制与一次性半随机附魔，结果会保留到重试。
- 响应式 HUD、车机字幕、程序生成音效及静音和音量调节。

## 当前限制

- 车辆、山体、树木和路牌使用代码生成的低多边形模型。
- 音效由 Web Audio 程序生成；车机播报以字幕为主。
- 自动化逻辑测试使用 Node.js 内置测试运行器。
